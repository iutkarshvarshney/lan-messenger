# Private account recovery and Ludo motion

Recovery is owned by the user. The owner confirms their current password in Account security, generates ten random 128-bit codes and downloads them once. Only SHA-256 hashes linked to the account are stored. Verifying one consumes it and creates a random restricted reset token, valid for two minutes. This token has no login, chat, file or socket privileges. The owner sets and confirms a password with at least twelve characters (up to bcrypt's72-byte UTF-8 limit), then signs in normally. All previous JWT sessions, pending reset tokens and remaining old recovery codes are revoked. The owner must save a fresh code set after signing in. Failed verification uses a generic response with bounded per-account/IP attempt limits; code generation requires password reauthentication. Recovery material stays out of URLs, localStorage and logs. An unused-code count is the only status returned later. The control panel retains user list/deletion but cannot set user passwords or generate codes. Existing temporary-password sessions are limited to password change and expiry. Device fingerprint reset is removed.

Codes are not OTPs delivered to a device. They belong to the account, not an IP or MAC address. Existing accounts must proactively save codes before losing access. Recovery does not reconstruct browser encryption keys; a stable HTTPS hostname preserves browser-origin continuity when server IPs change. Chats, uploads, prekeys and local keys are not rewritten by account recovery. This does not claim protection against a server administrator changing the software or accessing server-held data.

Ludo base circles are centered in all four yards. Finished pieces occupy their own coloured triangle. Shared geometry drives board rendering and token paths. Server state stays authoritative; movement hops160ms per square, capture returns260ms after arrival, input is disabled during presentation, later states queue, and close cancels animation frames. Reduced motion applies the final position immediately. Canvas borders are excluded from pointer coordinate mapping, and resize uses the actual content size. No game rule changes.

Validation: focused geometry/motion/security tests plus the full suite, isolated HTTP/socket recovery attack tests, and browser QA at desktop/mobile widths. Guidance: https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html
